# marketvalley 린캔버스

상태: 검증 전 가설 v0.1
기준일: 2026-08-25

이 문서의 고객 반응, 가격과 채널은 검증 전 가설이다. 실제 인터뷰·결제·캠페인 결과처럼 표현하지 않는다.

## 고객 세그먼트

첫 고객:

- 아이디어는 있지만 제품을 아직 만들지 않은 예비창업가
- 혼자 또는 극소수로 준비하며 첫 시장 반응을 확인하려는 사람
- 개발자·마케터·디자이너를 고용하기 전에 수요 신호를 보고 싶은 사람
- 첫 검증 채널로 랜딩페이지와 Instagram을 사용할 수 있는 사람

초기 제외 대상:

- 이미 마케팅 조직과 브랜드 시스템을 가진 회사
- 통계적으로 유의한 대규모 리서치가 필요한 조직
- 실제 광고 자동 집행과 성과 최적화가 핵심인 전문 마케터

## 문제

예비창업가는 아이디어의 성공을 확신하지 못해 시작을 미룬다. 확신이 없는 원인을 단순 정보 부족이 아니라 첫 행동 검증을 설계하고 실행하는 방법을 모르는 문제로 본다.

현재 반복되는 일:

1. 고객·문제·솔루션을 채널마다 다시 정리한다.
2. 랜딩페이지 구조와 문구를 만든다.
3. 카드뉴스 흐름과 장별 문구를 따로 작성하고 조판한다.
4. 게시 문구, CTA와 링크를 다시 맞춘다.
5. 흩어진 반응을 취합해 처음 가설과 비교한다.

가장 큰 위험은 제작 시간이 길다는 것보다 제작 과정에서 메시지가 달라지고 실제 고객 반응을 받기 전에 검증이 멈추는 것이다.

## 고유 가치 제안

`아이디어만 입력하면 첫 행동 검증에 필요한 캠페인이 하나의 가설로 연결되고, 결과를 본 뒤의 판단은 사람에게 남는다.`

marketvalley는 시장성을 대신 판정하지 않는다. 검증 캠페인의 반복 제작·정리 업무를 없애 실제 고객 반응과 사람의 다음 결정을 연결한다.

## 솔루션

- 고객·문제·솔루션·기대 신호·반증 조건을 구조화한 검증 가설
- 같은 `CampaignSpec`을 쓰는 공개 랜딩과 Instagram 캐러셀 5장
- 게시 문구·CTA·공개 URL을 묶은 `Meta 게시 준비`
- 이름·이메일·동의를 받는 예약자명단과 접수 추이
- 사전 판단 기준, 표본 부족 표시와 사람의 다음 행동 저장

## 채널 가설

- 교내·지역 창업동아리와 예비창업자 커뮤니티
- 창업보육센터, 대학 창업지원단과 IT·창업 교육기관
- 초기 아이디어 검증 워크숍과 멘토링 프로그램
- marketvalley가 만든 공개 캠페인 하단의 제품 유입

## 수익 모델 가설

| 고객 | 초기 가설 | 반드시 검증할 질문 |
| --- | --- | --- |
| B2C 예비창업가 | 캠페인 1건 단위 결제 | 무료 대안 대신 결과물·공개·취합까지 묶인 흐름에 지불하는가? |
| B2C 반복 사용자 | 월 단위 여러 캠페인 | 같은 사용자가 서로 다른 아이디어를 반복 검증하는가? |
| B2B 창업지원기관 | 프로그램·기수 단위 계약 | 운영자가 참가팀 결과를 일관된 형식으로 관리하는 가치가 있는가? |

팀 기획에서 제시된 B2C 건당 10만~20만 원은 가격 가설일 뿐이다. 실제 지불 의향 인터뷰와 결제 실험 전에는 가격표나 매출 전망으로 확정하지 않는다.

## 비용 구조

- Anthropic 생성 호출
- Supabase 저장·전송
- Oracle Compute 단일 VM, Docker image build와 HTTPS 전송
- 고객지원, 사실성 검토와 템플릿 운영
- Meta 연동 시 OAuth·권한·정책 변경 대응

## 핵심 지표

제품 가치 지표:

- 제거된 수작업 단계와 도구 간 재입력
- 제거된 채널별 문구 재작성과 파일 정리
- 공개 후 별도 취합 없이 연결된 예약자명단
- 예외 발생 후 재작업률

검증 지표:

- 실제 예약자 수와 접수 추이
- 사전 최소 표본 대비 현재 예약자 수
- 사람이 저장한 다음 행동

방문 이벤트 전에는 랜딩 응답률을 표시하지 않고 Meta Insights 전에는 링크 CTR을 표시하지 않는다.

## 방어력 가설

- 채널별 생성 기능이 아니라 검증 가설과 반증 조건에서 실제 반응까지 이어지는 단일 데이터 계약
- 랜딩·카드·게시 문구·결과가 같은 source field를 사용하는 일관성
- 실패해도 사람의 승인과 되돌릴 수 있는 fixture/live adapter 경계

## 가장 위험한 가설

1. 예비창업자가 실제로 검증 방법을 몰라 시작을 미루고 있다.
2. 랜딩과 카드 제작을 묶는 것보다 반응 취합과 다음 판단 연결에 더 큰 가치를 느낀다.
3. 동의 기반 예약 행동이 첫 실험을 시작하기에 충분한 최소 증거다.
4. 완전 자동 판정보다 공개 전 검토와 최종 판단 권한을 선호한다.
5. 개인 결제 또는 창업지원기관 계약 의향이 있다.

우선 검증은 최근 아이디어 검증을 시도하거나 포기한 예비창업자 3명의 실제 행동 인터뷰로 시작한다. 인터뷰가 완료되기 전에는 위 가설을 사실로 바꾸지 않는다.
