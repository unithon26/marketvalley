# 3분 발표 구성

상태: 운영 lifecycle 기준
기준일: 2026-08-26

## 핵심 문장

`marketvalley는 콘텐츠를 더 만드는 도구가 아니라, 예비창업자가 첫 고객 반응을 보기 전 반복하던 제작·등록·확인·취합을 없애는 도구입니다.`

## 슬라이드와 멘트

### 1. 사람과 상황 — 20초

아이디어는 있지만 아직 제품과 마케팅 조직이 없는 예비창업가를 보여준다.

“첫 고객을 만나기도 전에 같은 가설을 랜딩, 카드뉴스와 Ads Manager에 반복해서 옮기고 다음 날 데이터를 다시 합쳐야 합니다.”

### 2. 사라져야 할 일 — 25초

고객·문제 재작성, 랜딩 제작, 카드 조판, 게시 문구 재입력, 광고 등록, 상태 확인과 반응 취합을 하나의 Before 흐름으로 보여준다. 시간 절감률을 추측하지 않고 실제로 제거된 조작과 인계만 말한다.

### 3. 제품 원리 — 20초

하나의 `CampaignSpec`과 DB 상태 머신이 Claude, 랜딩, 캐러셀, Meta 광고와 리포트를 연결하는 그림을 보여준다.

“브라우저가 작업을 붙잡고 있지 않습니다. 접수를 먼저 저장하고 서버가 다음 날까지 이어서 처리합니다.”

### 4. 실제 데모 — 75초

1. Google 로그인 뒤 계정 소유 프로젝트만 나타나는 홈을 보여준다.
2. 두 입력을 제출하고 DB에 접수된 진행 화면으로 이동한다.
3. 실제 공개 랜딩과 Meta 광고에 올라간 서버 PNG 5장을 보여준다.
4. `접수 → 준비 중 → 수집 중 → 결과 도착`이 새로고침과 재로그인 뒤에도 복원되는 것을 보여준다.
5. 실제 수집이 끝났다면 최종 Insights·방문·예약 리포트를 연다. 수집 중이면 별도 발표용 완료 예시의 라벨을 숨기지 않고 보여준다.
6. 마지막에 사람이 `계속 검증`, `메시지 수정`, `보류`를 선택한다.

### 5. 없어진 일의 증거 — 25초

- 채널별 카피 재작성 제거
- 랜딩과 카드 5장의 수동 조판·파일 정리 제거
- Ads Manager 소재 재입력과 다음 날 상태 확인 제거
- Meta·방문·예약 데이터의 별도 취합 제거
- 남은 사람의 역할: 문제 선택, 사실성 책임, 고객 대화와 다음 행동 판단

### 6. 한계와 다음 검증 — 15초

“클릭이나 예약만으로 시장성이 검증됐다고 말하지 않습니다. 다음 단계는 실제 예비창업자의 반복 업무가 얼마나 사라졌고 예외 재작업이 얼마나 남았는지 측정하는 것입니다.”

## 예상 질문

### Canva·Lovable과 무엇이 다른가?

결과물 생성에서 끝나지 않는다. 검증 가설과 반증 조건을 고정하고, 실제 광고·방문·예약을 같은 가설에 연결한 뒤 사람의 다음 판단으로 끝난다.

### 응답이 적은데 시장성을 판단할 수 있나?

판단하지 않는다. 실제 관찰값과 사전 기준을 보여주고 다음 행동은 사람이 선택한다.

### 개인정보를 왜 받나?

후속 안내를 받을 의사가 있는 행동을 확인하기 위해 이름·이메일만 명시적 동의 뒤 수집한다. 같은 이메일 중복을 막고 소유자 목록에서도 마스킹한다.

### Meta 광고를 정말 집행하나?

팀 소유 테스트 광고계정의 한정된 lifetime 예산으로 실제 객체를 만들고 활성 상태와 Insights를 확인했다. 운영자·계정·예산 exact match와 live run unique 제약이 없으면 자동 활성화되지 않는다. 결제수단 등록, 예산 증액과 종료 광고 재시작은 자동화하지 않는다.

### AI가 꼭 필요한 부분은?

자유 형식 아이디어를 고객·문제·솔루션·기대 신호·반증 조건과 채널별 길이 제한을 만족하는 단일 구조 계약으로 변환하는 부분이다. 조판, 상태 전이와 집계는 결정적 코드가 담당한다.

### 탭을 닫거나 외부 API가 실패하면?

입력을 Supabase에 먼저 저장하고 worker가 lease와 checkpoint에서 재개한다. 일시 오류는 `RETRY_WAIT`, 자동 복구가 위험한 오류는 `FAILED`로 남기며 성공으로 위장하지 않는다.
