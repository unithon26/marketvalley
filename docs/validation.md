# 검증 체크리스트

상태: 구현 전 계획

현재 저장소에는 제품 코드가 없다. 개발환경 자체는 다음 명령으로 확인한다.

```bash
pnpm check
```

이 명령은 lint, TypeScript 설정과 빈 테스트 실행 환경만 검증하며 제품 동작이나 production build 통과를 뜻하지 않는다.

## 구현 후 자동 검증

```bash
pnpm lint
pnpm typecheck
pnpm test
pnpm build
```

- `lint`, `typecheck`, 단위 테스트와 production build가 오류 없이 끝난다.
- 템플릿 통합 후 E2E 도구를 선정해 외부 키와 네트워크 없이 핵심 수동 흐름을 재현한다.
- E2E는 개발 회귀 검증에만 사용하며 발표 자동 재생이나 자동 클릭 기능으로 제공하지 않는다.

## 구현 후 핵심 기능

- 예시 입력에서 하나의 유효한 `CampaignSpec`이 생성된다.
- 프로젝트명, 가치 제안, CTA 수정이 랜딩과 캐러셀에 함께 반영된다.
- `/p/demo`에서 선택형 응답 한 건을 제출할 수 있다.
- 같은 브라우저의 두 번째 응답은 거절된다.
- 응답 분포와 사전 판단 기준이 사실대로 표시된다.
- 사람이 선택한 다음 행동이 새로고침 뒤에도 유지된다.
- 5장 PNG를 개별 파일과 ZIP으로 내려받을 수 있다.
- `Meta 게시 준비`는 실제 등록 완료로 표현되지 않는다.

## 구현 후 화면과 접근성

- 375px에서 가로 스크롤 없이 핵심 CTA가 보인다.
- 발표 노트북 해상도에서 네 탭과 주요 상태가 구분된다.
- 키보드만으로 입력, 탭, 공개, 응답과 판단을 조작할 수 있다.
- focus 상태, label, dialog 설명과 오류 문구가 있다.
- 긴 한글 문구가 잘리거나 `undefined`로 보이지 않는다.
- PNG 결과가 1080×1350이고 `01-hook.png`부터 `05-cta.png` 순서다.

## 안전성과 진실성

- 이름, 이메일, 전화번호를 받지 않는다.
- API 키가 클라이언트 bundle, Git, 로그와 화면에 없다.
- 모든 seed 응답과 fixture는 `데모 데이터`로 표시된다.
- 근거 없는 후기, 사용자 수, 효능·매출 수치와 인증이 없다.
- 시장 검증 완료나 실제 광고 집행을 주장하지 않는다.
