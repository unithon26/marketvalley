# ADR-0009: Figma 산출물 템플릿을 CampaignSpec에 고정한다

상태: 채택

기준일: 2026-08-25

## 배경

공유 Figma의 `템플릿 : 카드뉴스/랜딩페이지` 페이지에는 1080×1350 카드뉴스 표지 `31`, `32`, `34`와 랜딩 도입부 고정안 `1`부터 `7`까지가 있다. 기존 구현은 캐러셀과 공개 랜딩의 기능 흐름은 완성했지만, 캠페인마다 문구와 색상만 바꾸고 하나의 공통 레이아웃을 사용했다. 이 방식은 디자이너가 전달한 고정 템플릿을 실제 산출물로 사용한다는 합의와 맞지 않았다.

## 결정

- `CampaignSpec`을 v2로 올리고 `templates.carouselCover`와 `templates.landingIntro`를 필수 필드로 둔다.
- `carouselCover`는 `cover-31`, `cover-32`, `cover-34`만 허용한다. 첫 번째 Hook PNG는 선택된 표지 레이아웃을 사용하고 나머지 네 장은 기존의 결정적 흐름을 유지한다.
- `landingIntro`는 `intro-1`부터 `intro-7`까지만 허용한다. 공개 랜딩의 도입부는 선택된 Figma 고정안을 사용하고 문제·가치·작동 방식·익명 신호·FAQ는 공통 섹션을 재사용한다.
- 텍스트와 색상은 동일한 `CampaignSpec`에서 가져온다. 임의 좌표나 HTML을 생성하거나 자유 편집기를 만들지 않는다.
- reference fixture 세 종은 서로 다른 표지와 랜딩 도입부를 선택해 mock 단계에서도 템플릿 경계를 검증한다.

표지 `32`와 `34`의 래스터 배경은 팀 공유 Figma에서 내려받은 원본을 사용한다. Figma Inspect에 원출처와 라이선스가 표시되지 않으므로 공개 제출 전에 디자이너가 사용권을 확인한다.

## 기각한 대안

### 브랜드 tone에서 템플릿을 암묵적으로 추론한다

계약에는 선택 결과가 남지 않고, OpenAI·Supabase adapter가 연결될 때 같은 snapshot이 다른 화면으로 렌더링될 수 있어 기각했다.

### 한 가지 공통 레이아웃만 유지한다

구현은 단순하지만 전달된 Figma 산출물 템플릿을 사용하지 못해 기각했다.

### AI가 전체 레이아웃이나 글자가 든 이미지를 생성한다

결과 재현성, 글자 품질, 안전 검토와 PNG 회귀 검증이 어려워 기각했다.

## 결과

mock과 향후 live adapter는 템플릿 ID까지 포함한 같은 snapshot을 저장한다. 화면과 ZIP은 같은 결정적 React/CSS 렌더러를 사용하며, 지원하지 않는 템플릿 ID는 Zod 경계에서 거절된다. 새 템플릿을 추가할 때는 계약, 렌더러, fixture와 시각 회귀 검증을 함께 변경해야 한다.
