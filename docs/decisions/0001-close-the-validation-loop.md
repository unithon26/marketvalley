# ADR-0001: 소재 생성기가 아니라 검증 루프를 닫는다

상태: 채택
날짜: 2026-08-24

## 배경

초기 아이디어는 1인 사업자의 설명에서 랜딩페이지, 후킹 문구, 인스타그램 카드를 자동으로 만드는 것이었다. 그러나 HubSpot, Canva, Lovable, Unbounce, AdCreative.ai가 이미 이 범위의 상당 부분을 제공한다. 생성할 자산 수만 늘리면 기존 제품의 축소판으로 보이고, 대회의 “무엇을 사라지게 했는가”에도 약하게 답하게 된다.

## 결정

제품의 완료점을 산출물 생성이 아니라 첫 검증 실험의 닫힌 루프로 정한다.

`아이디어 → 검증 가설과 반증 조건 → 일관된 랜딩·캐러셀·카피 → 공개 → 관심 신호 수집 → 사람의 다음 판단`

모든 산출물은 하나의 `CampaignSpec`에서 만들어진다. 실제 광고 플랫폼 게시와 집행은 제외하지만, 생성된 랜딩페이지는 공개 URL로 제공하고 개인정보 없는 선택형 관심 응답을 원래 가설과 사전 판단 기준에 연결한다. 응답 이후에는 AI가 결론을 내리지 않고 사용자가 `계속 검증`, `메시지 수정`, `보류`를 선택하며 그 선택을 캠페인에 저장한다.

## 기각한 대안

### 랜딩과 광고 소재만 대량 생성

구현은 쉽지만 기존 제품과 차별이 약하고 “더 빠른 제작”에 머문다.

### Instagram과 Meta까지 자동 게시

발표의 즉각적인 효과는 있지만 계정 인증, 권한, 검수, 외부 API 실패와 실제 계정 쓰기 위험이 크다. 핵심 문제보다 연동에 시간을 소비한다.

### AI가 시장성을 자동 판정

짧은 기간과 작은 표본으로 시장성을 판정할 근거가 없다. 사용자의 사업 판단까지 지우면 대회의 “사람을 남기자”와도 충돌한다.

## 결과

- 실제 선택형 응답 저장과 사람의 다음 행동 화면이 P0가 된다.
- 산출물 개수보다 채널 일관성과 가설 연결을 우선한다.
- 발표의 마지막은 AI의 결론이 아니라 사업자의 다음 판단이다.
- 시장 검증이나 사업 성공을 보장한다는 표현을 사용하지 않는다.
